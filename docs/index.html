Static GitHub Pages demonstration
This page is a static demonstration. It is plain HTML, CSS and JavaScript hosted on GitHub Pages. It does not talk to the Flask backend and does not store anything on a server. Submissions you add below stay in your browser tab until you refresh the page. The real portal, with persistent SQLite storage and server-side validation, runs locally with python run.py.
